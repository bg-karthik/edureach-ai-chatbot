# 🎓 EduReach — AI College Chatbot & Voice Agent

EduReach is an AI-powered college assistance platform designed to help students with admissions, course details, placements, and counseling through intelligent chat and voice interactions.

The platform uses Retrieval-Augmented Generation (RAG) with Google Gemini and MongoDB to provide accurate, context-aware responses.

# ✨ Features

- 💬 AI-powered chatbot using RAG architecture
- 📞 AI voice call assistant using Vapi AI
- 🔐 JWT-based user authentication
- 📚 Knowledge base integration for contextual responses
- ⚡ Real-time AI responses
- 🎯 Personalized counseling assistance
- ☁️ Cloud deployment using Vercel and Render
- 📱 Responsive modern UI
